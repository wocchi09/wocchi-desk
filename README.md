# Wocchi Desk

予定とタスクから、その日に何をするべきかを整理する個人用秘書ツールです。外部フレームワークやAPIを使わない静的Webアプリで、データはブラウザの `localStorage` に保存します。

**公開URL:** https://wocchi09.github.io/wocchi-desk/

## 主な機能

- 予定の追加・編集・削除、日付・時刻・メモの設定
- タスクの追加・編集・削除・完了チェック、期限・優先度・所要時間の設定
- 今日・明日・指定日の表示切り替え
- 期限超過、優先度、期限を考慮したタスクの自動並び替え
- 8:00〜20:00を対象とした30分以上の空き時間検出
- 予定の重複検出
- 予定数、優先タスク上位5件、空き時間、注意点をまとめた秘書レポート
- タスク総所要時間が空き時間を超える場合の警告
- 次の予定までに完了できるタスクの提案
- スマートフォン向け1カラム表示
- ホーム画面・デスクトップへ追加できるPWA構成
- Service Workerによるオフライン起動
- JSON形式のバックアップと復元
- Supabase接続時のメールログインと端末間同期

## 使い方

`index.html` をブラウザで開くだけで利用できます。ローカルサーバーを使う場合は、リポジトリ直下で次を実行してください。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## データ保存

データは同じブラウザ・同じオリジンの `localStorage`（キー: `wocchi-desk-v1`）に保存されます。サーバーへの送信はありません。ブラウザのサイトデータを削除すると登録内容も消えるため、重要な情報の唯一の保管場所にはしないでください。

保存データが破損している場合は、読み込めるデータだけを検証して利用し、アプリ自体は継続して動作します。

設定画面からJSONバックアップを書き出せます。クラウド未設定時も、これまでどおり端末内だけで利用できます。

## PWAとしてインストールする

- iPhone/iPad: Safariの共有メニューから「ホーム画面に追加」→「Webアプリとして開く」
- Android/PC: 対応ブラウザの「アプリをインストール」または「ホーム画面に追加」

一度オンラインで読み込むと、主要画面はオフラインでも起動できます。オフライン中の変更は端末内へ保存されます。

## Supabaseで端末間同期を有効にする

1. Supabaseでプロジェクトを作成します。
2. SQL Editorで `supabase/schema.sql` を実行します。
3. AuthenticationのURL設定に公開URL `https://wocchi09.github.io/wocchi-desk/` を追加します。
4. `config.example.js` を参考に、`config.js`へProject URLと公開可能なPublishable key（またはanon key）を設定します。
5. GitHub Pagesへ再公開し、設定画面から自分のメールアドレスへログインリンクを送ります。

`service_role`キーや秘密鍵は、リポジトリやブラウザ用コードへ絶対に記載しないでください。データへのアクセスは `schema.sql` のRow Level Securityでログインユーザー本人だけに制限します。

## GitHub Pagesで公開する

1. リポジトリをGitHubへpushします。
2. **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開ブランチのルート（`/`）を指定します。

ビルド工程は不要です。

## ファイル構成

- `index.html`: 画面構造と入力ダイアログ
- `styles.css`: カードUI、ネイビーの配色、レスポンシブ表示
- `app.js`: データ保存、CRUD、日付切り替え、分析、描画
- `cloud.js`: Supabase認証と端末間同期
- `config.js`: クラウド接続設定（初期状態は空）
- `manifest.webmanifest` / `sw.js`: インストール情報とオフラインキャッシュ
- `supabase/schema.sql`: 同期テーブルとアクセス制御

## 現在の制約

- 空き時間の判定対象は8:00〜20:00です。
- クラウド同期には利用者自身のSupabaseプロジェクト設定が必要です。
- 通知、繰り返し予定、外部カレンダー連携は未対応です。
- データは端末・ブラウザごとに保存されます。
