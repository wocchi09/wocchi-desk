# Wocchi Desk

予定とタスクから、その日に何をするべきかを整理する個人用秘書ツールです。外部フレームワークやAPIを使わない静的Webアプリで、データはブラウザの `localStorage` に保存します。

**公開URL:** https://wocchi09.github.io/wocchi-desk/

## 主な機能

- 予定の追加・編集・削除、日付・時刻・メモの設定
- タスクの追加・編集・削除・完了チェック、期限・優先度・所要時間の設定
- 今日・明日・指定日の表示切り替え
- 期限超過、優先度、期限を考慮したタスクの自動並び替え
- 8:00〜20:00を対象とした30分以上の空き時間検出
- 予定の重複検出
- 予定数、優先タスク上位5件、空き時間、注意点をまとめた秘書レポート
- タスク総所要時間が空き時間を超える場合の警告
- 次の予定までに完了できるタスクの提案
- スマートフォン向け1カラム表示

## 使い方

`index.html` をブラウザで開くだけで利用できます。ローカルサーバーを使う場合は、リポジトリ直下で次を実行してください。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## データ保存

データは同じブラウザ・同じオリジンの `localStorage`（キー: `wocchi-desk-v1`）に保存されます。サーバーへの送信はありません。ブラウザのサイトデータを削除すると登録内容も消えるため、重要な情報の唯一の保管場所にはしないでください。

保存データが破損している場合は、読み込めるデータだけを検証して利用し、アプリ自体は継続して動作します。

## GitHub Pagesで公開する

1. リポジトリをGitHubへpushします。
2. **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開ブランチのルート（`/`）を指定します。

ビルド工程は不要です。

## ファイル構成

- `index.html`: 画面構造と入力ダイアログ
- `styles.css`: カードUI、ネイビーの配色、レスポンシブ表示
- `app.js`: データ保存、CRUD、日付切り替え、分析、描画

## 現在の制約

- 空き時間の判定対象は8:00〜20:00です。
- データの同期、バックアップ、通知、繰り返し予定、外部カレンダー連携は未対応です。
- データは端末・ブラウザごとに保存されます。
